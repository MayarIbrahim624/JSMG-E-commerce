# JSMG – Women’s Lifestyle E-Commerce Website 👩‍💻🛍️

This project was created as part of a task assigned by the **IEEE Student Branch – Helwan University (IEEE SB HU).**

**JSMG** is a modern, responsive e-commerce website tailored for women’s lifestyle. It features products, services, and user-friendly content designed to create a complete and engaging shopping experience.

The project was developed by a team of four students, and the name **JSMG** comes from the initials of the team members:
- **Jana**
- **Sama**
- **Mayar**
- **Gehad**

## 🛠️ Technologies Used

- **HTML5** – Page structure and layout  
- **CSS3** – Styling and responsive design  
- **JavaScript** – Dynamic interactions  
- **Bootstrap** – Grid system and UI components  
- **Fake Store API** – Used to fetch and display product data

---

Website Pages
Home Page – Introduction and highlights of the website (by Mayar)

Products Page – Displays all products dynamically from the API (by Gehad)

Product Details Page – Shows detailed information about each product (by Gehad)

Login & Register Pages – For user authentication (UI only) (by Sama)

Cart Page – Displays items added to the shopping cart (by Jana)

About Us Page – Description of the team and project (by Jana)

---

## ✨ Key Features

- Fully **responsive design** for all screen sizes
- **Dynamic product display** using Fake Store API
- Dedicated **Product Details** page for individual items
- Functional **Cart** system for managing selected items
- Clean and simple **Login/Register** UI
- Clear **team role distribution** and organized codebase
